# ✅ Phase 00 Checklist: GitHub Foundation

> “Before building detections, build the place where detections can live without becoming folder soup.” 🍲

This checklist tracks the setup of my GitHub repository for detection engineering, threat hunting, malware analysis, YARA, Sigma, KQL, Suricata, Python automation, and phase-wise learning notes.

Phase 00 is about one thing:

> **Build a clean GitHub foundation before adding serious detection work.**

---

## 🎯 Phase Objective

Create a professional GitHub repository structure that can support:

* Detection engineering rules
* KQL hunting queries
* Sigma rules
* YARA rules
* Suricata rules
* Python helper scripts
* Malware analysis notes
* Lab architecture documentation
* Phase-wise learning notes
* Detection validation writeups
* Future detection-as-code workflows

This phase is considered complete when the repository has a clear structure, useful README files, safe documentation rules, and enough organization that future me does not need a shovel to find things. 🪦
