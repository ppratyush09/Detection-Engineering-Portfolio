# Detection Engineering Portfolio

This repository contains my hands-on detection engineering practice, including detection rules, hunting queries, lab notes, validation writeups, and detection-as-code learning.

## Focus Areas

* Sigma rule writing
* Microsoft Sentinel KQL hunting queries
* YARA rule development
* Suricata network detection rules
* Windows attack behavior detection
* Threat hunting and incident response use cases
* Detection validation in a home lab
* GitHub-based detection-as-code practice

## Repository Structure

| Folder               | Purpose                                                |
| -------------------- | ------------------------------------------------------ |
| `docs/`              | Lab notes, architecture, learning logs, and references |
| `sigma/`             | Sigma detection rules                                  |
| `kql/`               | Microsoft Sentinel / Defender hunting queries          |
| `yara/`              | YARA rules for file and malware-pattern detection      |
| `suricata/`          | Suricata IDS rules                                     |
| `reports/`           | Detection writeups and research notes                  |
| `tests/`             | Test events, validation notes, and safe test data      |
| `.github/workflows/` | Future CI/CD validation workflows                      |

## Current Lab Goal

The goal of this repository is to document my journey toward becoming stronger in detection engineering through practical lab work, rule development, validation, and clear technical writeups.

## Safety Notice

All content in this repository is created for educational and lab purposes only.
No company data, client data, proprietary detections, credentials, private logs, or real malware samples will be uploaded here.
